Adam AI Control Center V1 (Prototype)
- Arabic RTL responsive web app.
- Local-only task/project/chat demo.
- No backend, no Dify connection, no external actions.
To run: open index.html in a modern browser.
For installable PWA/service worker, host over HTTPS (or localhost) and add to home screen.
All prototype data is stored in browser localStorage; clearing browser data removes it.
